
# Images

This directory contains screenshots captured during different stages of the ASIC design flow for the **4-bit Up/Down Counter** implementation.

| Image | Description |
|-------|-------------|
| `01_functional_simulation.png` | RTL functional simulation waveform showing correct up/down counter operation. |
| `02_coverage.png` | Code coverage report generated using IMC after functional verification. |
| `03_area_report.png` | Area utilization report after RTL synthesis in Cadence Genus. |
| `04_delay_report.png` | Timing delay report generated after synthesis. |
| `05_power_report.png` | Power estimation report after synthesis. |
| `06_gate_report.png` | Gate count report of the synthesized design. |
| `07_dft_schematic.png` | Schematic of the design after DFT scan insertion. |
| `08_post_synthesis_simulation.png` | Post-synthesis simulation waveform. |
| `09_lec.png` | Logic Equivalence Checking (LEC) results verifying RTL and synthesized netlist equivalence. |
| `10_floorplan.png` | Initial floorplan generated in Cadence Innovus. |
| `11_power_ring.png` | Power ring implementation around the core. |
| `12_power_stripes.png` | Horizontal and vertical power stripe generation. |
| `13_placement.png` | Standard-cell placement after placement optimization. |
| `14_cts.png` | Clock Tree Synthesis (CTS) visualization. |
| `15_routing.png` | Final routed design after detailed routing. |
| `16_post_route_gls.png` | Post-route gate-level simulation results. |
| `17_sdf_simulation.png` | SDF delay simulation with extracted delays. |
| `18_sta.png` | Static Timing Analysis (STA) results using Cadence Tempus. |
| `19_power_analysis.png` | Final power analysis report generated using Cadence Voltus. |
